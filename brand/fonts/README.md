# Fonty marki KOLSYSTEM

## Rodziny

- Chakra Petch - nagłówki i język marki,
- Titillium Web - tekst ciągły,
- JetBrains Mono - dane techniczne i etykiety.

Katalog `desktop/` zawiera pełne pliki TTF z zestawem latin i latin-ext. Generator buduje je
z podzbiorów WOFF2 używanych przez stronę. Katalog `licenses/` zawiera pełne teksty licencji
SIL Open Font License 1.1 pobrane z oficjalnego repozytorium Google Fonts.

Fonty wolno osadzać, modyfikować i redystrybuować zgodnie z warunkami odpowiedniej licencji
OFL. Przy przekazywaniu fontów zachowaj właściwy plik licencyjny.
